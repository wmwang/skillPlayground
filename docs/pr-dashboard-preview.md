# PR Dashboard 範例報告 (Preview)

這是一份由 `azure-devops-pr-dashboard` 技能產出的模擬報告範例，展示了當您執行 PR 巡邏與月度統計時，終端機輸出與 Claude 會解析的格式。

---

## 1. 即時 PR 看板巡邏 (`pr_dashboard.py`)

當您下指令 `PR 巡邏` 或 `PR dashboard` 時產出：

```text
📊 PR Dashboard — 2026-07-04 23:30

📋 組織：isosoman0009 | 專案：dev | 儲存庫：my-web-app
═══════════════════════════════════════════════════════════════════════

┌─────┬──────────────────────────────┬────────┬────────┬──────────────┬────────────┐
│ #ID │ 標題                         │ 建立者 │ 停留   │ 審查狀態     │ 未解決討論 │
├─────┼──────────────────────────────┼────────┼────────┼──────────────┼────────────┤
│ #42 │ feat: 修正登入頁 RWD 排版    │ alice  │ 🔴 7天 │ 0/2 已審     │ 3          │
│ #55 │ refactor: 重構 API middleware│ bob    │ 🟡 3天 │ 1/2 已審     │ 0          │
│ #61 │ docs: 更新部署手冊           │ charlie│ ⚪ 1天 │ 無審查者     │ 0          │
│ #68 │ draft: 購物車功能重構        │ david  │ 📝 8天 │ Draft        │ 1          │
└─────┴──────────────────────────────┴────────┴────────┴──────────────┴────────────┘

🚨 風險告警：
  🔴 PR #42 (my-web-app) 已停留 7 天、有 3 個未解決討論 → 建議催促審查者 alice/reviewer
  🟡 PR #55 (my-web-app) 已停留 3 天且尚未通過完整審查 → 建議確認進度
  ⚪ PR #61 (my-web-app) 尚未指派任何審查者 → 建議指派
  📝 PR #68 (my-web-app) 為 Draft 狀態且已放置 8 天 → 建議確認開發是否停滯

💡 管理建議：
  • 目前有 1 個 PR 嚴重停滯（超過 5 天），可能遇到瓶頸。
  • 共有 4 個討論尚未解決，集中在 #42 與 #68。
  • 請管理員指派 #61 的 Reviewer 以便開始進行 Code Review。
```

## 2. 月度歷史表現度量統計 (`pr_metrics.py`)

當您下指令 `PR 月度統計`、`PR 績效`、`PR metrics` 時產出：

```text
📊 PR 歷史表現月度度量統計報告 (過去 30 天)
📋 組織：isosoman0009 | 專案：dev | 儲存庫：my-web-app
═══════════════════════════════════════════════════════════════════════

🔍 正在深入分析 24 個已合併的 PR ...

📈 統計摘要與指標：
  • 已合併 PR 總數：24 個
  • 平均合併時間 (Average Lead Time)：38.5 小時 (1.6 天)
  • 中位數合併時間 (Median Lead Time)：18.0 小時 (0.8 天)
  • 平均每個 PR 討論次數：3.2 次
  • 平均每個 PR 審查者人數：2.1 人

💡 效能簡評：
  🟢 合併效率卓越：過半數的 PR 能在 24 小時內完成 Review 與合併。
  🟢 審查深度良好：討論互動熱烈，代碼把關嚴謹。

🏆 團隊活躍度排行 (Top 3)：
  【PR 貢獻者】
    1. alice (10 個 PR)
    2. bob (8 個 PR)
    3. charlie (6 個 PR)
  【活躍審查者】
    1. reviewer_master (15 次有效投票)
    2. reviewer_senior (12 次有效投票)
    3. alice (9 次有效投票)
```
